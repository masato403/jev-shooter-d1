# Jev と d1-3B の比較（2026-10-09〜10-16）

どちらにも同じ問題（状況の文章＋行動ごとの予測結果を書いた選択肢）を渡し、選択肢ごとの確率から 1 つ選ばせました。追加学習はしていません。

- Jev：TypeSafe 社のクラウド API（jev-1.13.0）。入力 100 万トークンあたり 0.042 ドル、出力は無料
- d1-3B：Liquid AI の判断専用モデル（30 億パラメータ）。RTX 5050 Laptop GPU（8GB）で動かす

## 1. 同じ 120 問を解かせる（Jev が実際にプレイした時の状況）

「被弾」は、当たってゲームオーバーになる行動を選んだ数です。

| 判断する側 | 問題文 | 1 回の時間 | 被弾（弾幕 / 上下左右） |
|---|---|---|---|
| Jev | 長い文 | 約 170〜220ms（ほとんどが通信） | 元の答え（基準） |
| Jev | 短い文 | 中央値 166 / 159ms | 1 / 2 |
| d1-3B（bf16） | 長い文 | 約 81〜150ms | 0 / 0 |
| d1-3B | 短い文（元の版） | 約 43〜56ms | 4〜6 回 |
| d1-3B（bf16＋CUDA グラフ） | 短い文 A | 56.6 / 44.2ms | 0 / 0 |
| d1-3B（FP8＋CUDA グラフ） | 短い文 A | 34.0 / 26.4ms | 0 / 0 |

短い文の元の版は、当たる行動を "hit" の一語で書いていました。シューティングでは「敵に当てる（良いこと）」とも読めるため、モデルがそれを選びました。"shot down (game over)" と言い換えると被弾は 0 になりました。

## 2. 遊ばせる：答えが出るまでゲームを止めて待つ方式

シードを変えて 5 回ずつ。

| 判断する側 | 上下左右 | 弾幕 | 1 回の時間（中央値） |
|---|---|---|---|
| d1-3B・長い文 | 5/5（13.3〜13.6 秒） | 5/5（19.6〜20.5 秒） | 86 / 153ms |
| d1-3B・短い文（元の版） | 0/5 | 0/5 | 26 / 35ms |
| Jev・短い文 | 3/5 | 3/5 | 224 / 223ms |
| Jev・長い文（10/9、1 回ずつ） | クリア 14.9 秒 | クリア 20.7 秒 | 約 170ms |

## 3. 遊ばせる：考えている間もゲームが進む方式（--realtime）

ロボットや車のように、機械を自動で動かす時に近い条件です。

| 判断する側 | 上下左右 | 弾幕 | 1 回の時間（中央値） |
|---|---|---|---|
| ルールで動く仮の AI | 5/5 | 5/5 | — |
| Jev・長い文 | 0/5 | 0/5 | 173 / 176ms |
| Jev・短い文 | 0/5 | 0/5 | 178 / 176ms |
| Jev・長い文＋遅れの見越し | 0/5 | 0/5 | 176 / 178ms |
| d1-3B・長い文（bf16） | 2/5 | 0/5 | 79 / 132ms |
| d1-3B・長い文＋見越し | 5/5 | 0/5 | 85 / 136ms |
| d1-3B・短い文 B（FP8）、見越しなし | 4/5 | 0/5 | 27 / 39ms |
| d1-3B・短い文 B（FP8）＋見越し | 5/5 | 2/5 | 28 / 39ms |
| d1-3B・短い文 A（FP8）＋見越し | — | 5/5（再実行では 4/5） | 約 26〜36ms |

Jev は 30 回すべてゲームオーバーでした。答えが届くまでの約 0.18 秒の間に弾が進み、選んだ時には状況が変わっています。

## 4. 費用

- Jev：1 回のプレイで約 0.0005〜0.006 ドル（約 0.1〜0.9 円、1 ドル 150 円）。10/9 にゲーム 3 本をクリアするまでで合計約 12.4 円
- d1-3B：API の費用はかからない（手元の GPU で動かす。VRAM は約 6.5GB）

## 分かったこと

- 止めて待つなら、Jev も d1-3B もクリアできる。考えている間もゲームが進むと、反応の速さが決め手になる（Jev 0/30、d1-3B は最大 5/5）。
- 速くするために文を短くすると、言葉の取り違え（"hit"）で正確さが落ちた。短くした文は、元の文と同じ問題で被弾の数を確かめてから使う。
- 選択肢そのものに「選ぶと何が起きるか」（安全か・狙えるか）を書くと、Jev も d1-3B も攻撃するようになった。
